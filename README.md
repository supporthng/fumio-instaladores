# Instaladores de Fumio

Aquí solo se publican los **instaladores** de Fumio para Windows (en *Releases*).
El código del programa no está en este repositorio.

- **Fumio-Setup-X.Y.exe**: instalador completo (servidor de la oficina; también sirve como terminal).
- **Fumio-Terminal-Setup-X.Y.exe**: instalador liviano para las terminales.
